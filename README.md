# 双轮差速机器人轨迹跟踪仿真

基于 **Webots + C** 的双轮差速机器人轨迹跟踪项目。机器人使用 GPS 和 IMU 获取位姿，沿预设的 61 个路径点运动，通过差速运动学计算左右轮速度。

当前控制器版本为 `tracking-fix-v2`，支持弯道自适应过点、提前减速、航向控制、终点停车和逐周期日志。

## 功能

- 统一使用弧度，处理航向跨越 ±π 的情况。
- 切换路径点时保留目标航向，并限制目标航向变化速率。
- 使用带微分滤波的 PD 控制角速度。
- 根据弯道角度调整过点半径，进入弯道前提前减速。
- 根据航向误差降低前进速度，偏差较大时原地转向。
- 换算左右轮角速度，超限时共同缩放，保留转弯比例。
- 接近终点时减速，在 1 cm 位置容差内停车。
- 通过轮编码器及 Supervisor 获取执行反馈，每周期记录 CSV。

## 环境要求

- **Webots**：世界文件采用 R2023a 格式，并引用该版本的远程 PROTO；未进行跨版本兼容性测试。
- **C 编译工具链**：用于构建 Webots 控制器。
- **Python 3**：日志分析只使用标准库，无需安装额外 Python 包。
- **MATLAB（可选）**：用于路径设计与绘图，不参与控制器运行。

当前主程序使用 Windows 目录及文件创建接口，已在 Windows 环境编译运行。Linux/macOS 使用前需适配相关接口。

## 快速开始

1. 下载或克隆仓库，保留目录结构。
2. 在 Webots 中打开 `worlds/wire_car.wbt`。
3. 在控制器编辑器中打开 `controllers/my_controller/my_controller.c`，构建 `my_controller` 控制器。
4. 重置或重新加载世界，再启动仿真。
5. 确认控制台显示以下版本信息：

   ```text
   [tracking-fix-v2] Log: logs/run_YYYYMMDD_HHMMSS_000.csv
   ```

机器人自动开始跟踪，完成后保持停车。按 **X** 关闭画笔，按 **Y** 开启画笔。

仓库默认不包含预编译程序，运行前需要构建。首次加载远程 PROTO 需要网络或已有本地缓存。修改源码后需重新构建并重置世界。

### 命令行构建

如果 Webots 构建工具已加入环境变量，并设置了 `WEBOTS_HOME`，可执行：

```powershell
cd controllers/my_controller
make
```

Makefile 通过 `WEBOTS_HOME` 引入 Webots 的 `resources/Makefile.include`。

## 控制方法

控制周期为 **64 ms**：

```text
GPS / IMU / Supervisor / 轮编码器
                 ↓
        路径进度与目标点更新
                 ↓
  航向平滑 + PD 角速度 + 弯道限速
                 ↓
       差速轮速解算与共同限幅
                 ↓
         左右电机 + CSV 日志
```

### 路径点与速度规划

路径定义在 `path.c`，坐标单位为 **mm**。导航运算转换为 **m**，速度使用 **m/s**，角度及角速度使用 **rad、rad/s**。

以目标点入射与出射线段的夹角绝对值作为转角：

| 路径转角 | 过点半径 | 到弯点的基础速度上限 |
|---|---:|---:|
| ≤ 20° | 7 cm | 0.1375 m/s |
| > 20° 且 ≤ 40° | 3.5 cm | 0.075 m/s |
| > 40° | 2 cm | 0.045 m/s |

进入过点半径后切换下一目标。若已越过目标的投影位置，且横向偏差小于对应半径，也允许切换，避免反复追逐已经越过的点。

弯前速度限制采用 `v_limit² = v_corner² + 2ad`，其中 `a = 0.04 m/s²`，`d` 为目标距离减去过点半径后的非负值。该包络用于提前减速，并非严格的底盘加速度闭环。

前进速度还乘以 `max(0, cos(航向误差))²`。目标方向误差超过 **45°** 时原地转向，小于 **15°** 时退出。最后一点使用距离比例减速，进入 **1 cm** 容差后停车。

### 差速运动学

设前向速度为 `v`、角速度为 `ω`、轮距为 `L`、轮半径为 `r`：

```text
ω_left  = (v - ωL/2) / r
ω_right = (v + ωL/2) / r
```

| 参数 | 数值 | 配置位置 |
|---|---:|---|
| 轮半径 | 0.025 m | `chassis.h`、世界模型 |
| 左右轮间距 | 0.09 m | `chassis.h`、世界模型 |
| 电机最大轮速 | 15 rad/s | 世界模型，运行时读取 |
| 巡航速度 | 0.1375 m/s | `path.c` |
| 导航线速度上限 | 0.18 m/s | `PID_Nav.c` |
| 导航角速度上限 | 1 rad/s | `PID_Nav.c` |
| 目标航向变化上限 | 每周期 5° | `PID_Nav.c` |
| 航向 PD 增益 | Kp = 4，Kd = 0.256 | `PID_Nav.c` |

当前控制链采用几何过点、速度规划及航向 PD。模糊 PID 源码保留，但不生成当前的平移控制指令。

## 日志与分析

每次启动创建独立日志：

```text
controllers/my_controller/logs/run_YYYYMMDD_HHMMSS_000.csv
```

日志每周期写入并刷新，中途停止也能保留已有数据。第一行为版本和参数元数据，第二行为 CSV 表头。另有 `controllers/my_controller/data.txt` 保存两列位置数据，每次运行覆盖。

在仓库根目录分析最新日志：

```powershell
python controllers/my_controller/analyze_log.py
```

分析指定文件：

```powershell
python controllers/my_controller/analyze_log.py controllers/my_controller/logs/run_YYYYMMDD_HHMMSS_000.csv
```

记录内容包括位置、目标点、距离、横向误差、目标航向、角误差、速度指令、轮速指令与反馈、实际底盘速度、弯道限速及策略状态。完整字段说明见 [RUN_LOG_GUIDE.md](controllers/my_controller/RUN_LOG_GUIDE.md)。

分析时注意：

- `index` 从 0 开始，范围为 0～60。
- `state`：11 表示跟踪，12 表示最后一点接近，10 表示完成停车。
- 当前行反馈对应采样时刻，命令用于下一仿真区间；比较执行误差时，应与上一行命令对齐。
- `cross_track_m` 是相对当前入射线段的有符号横向误差，不等于到整条路径最近线段的距离。
- 当前摘要脚本包含停车后的记录；比较跟踪性能时应排除 `state == 10`。到达时间应使用首次完成的时刻，而非日志最后时刻。
- 传感器出现非有限值时，控制器发送零轮速并记录 `sensor_invalid`。

## 仿真验证结果

以下为固定路径与当前模型下两次 Webots 运行的对照。误差采用**到预设折线路径最近线段的距离**，排除完成后停车的样本；前后半段按最近线段编号划分。

| 指标 | v1 | v2 |
|---|---:|---:|
| 前半段误差 RMS | 0.61 cm | 0.31 cm |
| 后半段误差 RMS | 0.97 cm | 0.46 cm |
| 全程最大误差 | 4.92 cm | 1.80 cm |
| 到达终点时间 | 218.75 s | 179.71 s |
| 最终位置误差 | 2.47 cm | 0.97 cm |

v2 本次运行没有无效传感器记录，也没有轮速指令饱和。这是单次运行对照，尚非重复实验统计结果。原始日志默认不上传，表中的最近线段指标也不是当前摘要脚本直接输出的活动线段指标。

`tests/controller_checks.c` 检查角度跨界、切点航向保留、轮速单位、转向符号、共同限幅、急弯过点半径，以及理想差速运动学下的完整路径到达与停车。该测试不模拟摩擦、打滑及传感器噪声，不能代替 Webots 物理运行。

## 已知限制与后续方向

- 当前逐点跟踪在急弯切点时仍有方向突变。v2 在下标 41、45 附近分别有约 0.83 s、0.77 s 的原地转向。
- 直接使用仿真 GPS、IMU 和 Supervisor 反馈，未实现真实机器人定位融合及里程计估计。
- 终点完成条件仅检查位置，不要求终点朝向。
- MATLAB 脚本含历史绘图及实验性导出片段，不能直接视为自动生成流水线。修改路径时需核对 `path.c` 与 `path.h` 的点数。
- 后续可引入连续前视目标或 Pure Pursuit，改善急弯连续性，并扩展不同速度、噪声与路面条件下的验证。
